# 放棄 RAG 吧！LLM 知識庫新範式 | Karpathy 的新思路

> [!quote]- 原始影片描述（已清理）
> Karpathy 最近分享了他構建個人知識庫的方法，徹底顛覆了我對知識管理的理解。
>
> 傳統的 RAG 系統每次查詢都是臨時檢索，知識沒有積累。但 Karpathy 用 LLM 構建的持久化 Wiki 不同——它讓知識自己生長。當你添加一篇新文章，LLM 不只是把它存起來等以後檢索，而是讀取它、提取關鍵信息，然後把它整合進整個知識網絡：更新實體頁面、標記矛盾、強化綜合。知識被編譯一次，然後持續保持更新。
>
> 這個視頻深度拆解了 LLM Wiki 的核心思想：為什麼傳統 RAG 總是不夠聰明？三層架構如何優雅地分離關注點？LLM 如何成為知識庫的「記帳員」？從攝入、查詢、歸檔到體檢的完整工作流是什麼樣的？這會如何改變企業知識管理的未來？
>
> Karpathy 說過一句話特別扎心：「每個企業都有一個 raw 目錄，但從來沒有人編譯過它。這就是產品。」這個視頻就是在講，如何用 LLM 來編譯你的知識。
>
> 開源實現已經出現（AgentMemory），這套方法完全可以落地。
>
