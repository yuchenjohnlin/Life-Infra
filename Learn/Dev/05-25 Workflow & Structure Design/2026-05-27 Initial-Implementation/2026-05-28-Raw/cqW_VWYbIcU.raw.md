# 谷歌AI的14年、Gemini翻身之战，与视觉理解模型：专访DeepMind前核心科学家Andrew Dai｜Neolabs特辑

## Description

Andrew Dai在谷歌的14年，可以说是这家科技巨头在深度学习时代的AI编年史。

他长期处于Google Brain和DeepMind的核心研究项目中：从早期启发了GPT的sequence learning、文本生成、对抗训练，到 MoE架构、PaLM、Flan、Gemini、多模态和长上下文等等。与他合作论文的，都是谷歌的众多传奇大佬人物：Quoc Le，Ian Goodfellow，Liam Fedus，Jeff Dean等人。

在Gemini 3.0顺利上线之后，Andrew选择离开。他看到了一条大公司“不敢走”的路——不是纯语言模型，也不是世界模型，而是语言与视觉推理的结合。他的新公司Elorian AI今年4月完成了5500万美元的融资，Jeff Dean以个人身份参投。

2026年的Google I/O在即，我们与Andrew一起回顾了谷歌过去14年的AI发展史：如何错过，如何落后，如何追赶，又如何重新封王。

硅谷没有秘密，但有一群信仰不一样未来的科学家们。在巨头们押注SOTA LLM之际，众多科技领军人物纷纷出逃，创建自己的AI前沿新实验室（Neolabs），他们不拼算力和参数，而是希望找到一条真正达到智能的路径。硅谷101开启Neolabs特辑，想和这群科学家们深度聊聊，他们眼中的AGI之路。这是该特辑的第一期视频播客，欢迎大家持续关注我们。
