# 研究者做文獻筆記，真正該外包給 AI 的不是理解，而是整理

## Description

📚 做研究的人最需要的，不只是讀更多文章，而是建立一套能把讀過的東西留下來、找得回來、用得上的系統。

這支影片，我想從頭跟你分享：
我怎麼把 Claude Code、Obsidian、Zotero 結合起來，建立一套自己每天都在用的文獻筆記 workflow。✍️🤖

在這支影片裡，我會示範：
✨ Claude Code 怎麼安裝
✨ Obsidian Vault 怎麼作為研究筆記空間
✨ Zotero 匯出的 bibliographic information 怎麼接進 workflow
✨ 我怎麼把文章正文貼給 Claude Code，讓它協助整理筆記
✨ 為什麼我不直接把整份 PDF 丟給 AI
✨ 如何讓 AI 幫我做 tag、分類、研究方法整理、主要發現整理
✨ 怎麼把文獻筆記跟自己的研究興趣連起來

我自己現在的做法是：
🧠 理解文章這件事，還是留給自己
🗂️ 整理、標記、分類、回收這件事，交給 AI 幫忙

因為在 AI 時代，知識取得會越來越容易，
但「知識管理」反而會越來越重要。📖

如果你也是研究生、老師，或是平常需要大量讀 paper 的知識工作者，
希望這支影片能幫你把文獻整理這件事做得更省力、更有系統。🚀

💬 如果你也有把 Claude Code、Obsidian 或 Zotero 結合在研究工作流裡，
歡迎留言跟我分享你的做法！
